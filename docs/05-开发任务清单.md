# 企业级知识库开发任务清单

> 执行原则：按阶段完成；每项任务只有在代码、测试和文档同时完成后才能勾选。  
> 架构：TypeScript/NestJS 主服务 + Python/FastAPI 文档解析 Worker。

---

## 0. 完成定义

每个任务的 Definition of Done：

- [ ] 实现符合 [01-项目实施规格.md](./01-项目实施规格.md)。
- [ ] 关键设计符合 [02-技术设计.md](./02-技术设计.md)。
- [ ] 包含成功、失败和权限相关测试。
- [ ] lint、类型检查、单元测试通过。
- [ ] 不包含真实 API Key、用户数据或本机绝对路径。
- [ ] `.env.example`、README 或相关文档同步更新。
- [ ] 日志不泄露密钥和完整敏感正文。
